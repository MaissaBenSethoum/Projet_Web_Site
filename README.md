# InsaNews

**InsaNews** est un site web interactif permettant de consulter des actualités personnalisées selon les centres d’intérêt de l’utilisateur.

Projet réalisé dans le cadre du module **Création de sites web interactifs** à l’INSA Rouen Normandie.

## Présentation

L’utilisateur commence par sélectionner les thèmes qui l’intéressent parmi plusieurs catégories : cinéma, histoire, politique, musique, écologie, faits divers, sport et jeux vidéo.

Les thèmes sélectionnés sont ensuite utilisés pour récupérer et afficher automatiquement des articles provenant de différentes APIs d’actualités.

Le projet met en pratique le principe des **échanges client/serveur** ainsi que la manipulation de données provenant d’APIs.

## Fonctionnalités

* Sélection personnalisée des centres d’intérêt
* Récupération d’articles depuis plusieurs APIs
* Affichage dynamique des actualités
* Articles complémentaires dans une barre latérale
* Suppression des articles en double
* Gestion des erreurs et affichage de contenus par défaut
* Interface adaptée aux thèmes sélectionnés

## Technologies utilisées

* **HTML / CSS** — structure et mise en page
* **JavaScript** — logique et interactions
* **Fetch API** — récupération des données
* **JSON** — traitement des données reçues
* **GNews, NewsAPI et MediaStack** — APIs d’actualités

## Fonctionnement

Le site est composé de plusieurs pages. Les thèmes sélectionnés par l’utilisateur sont transmis entre les pages afin de personnaliser le contenu affiché.

JavaScript récupère ensuite les articles via les APIs, les traite et génère dynamiquement leur affichage dans la page.

## Organisation

La structure actuelle du projet est volontairement simple, avec les fichiers HTML, CSS, JavaScript et les images du site.
